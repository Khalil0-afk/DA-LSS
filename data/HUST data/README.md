# HUST processed feature tables

This directory contains77 supplied processed CSVs with17 summary-feature/capacity columns. They are not the original within-cycle measurement archives.

Original study: [Ma et al., Real-time personalized health status prediction of lithium-ion batteries using deep transfer learning](https://pubs.rsc.org/en/content/articlehtml/2022/ee/d2ee01676a).

Original dataset: [Mendeley Data V2](https://data.mendeley.com/datasets/nsc7hnsg4s/2), DOI `10.17632/nsc7hnsg4s.2`.

Follow the original providers' terms. Preserve the supplied files and establish cycle identities and the capacity/SOH normalization rule before creating canonical model inputs. See [the dataset guide](../README.md).
