# MIT processed feature tables

This directory contains125 supplied processed CSV files arranged under `2017-05-12`, `2017-06-30` and `2018-04-12`. Files contain17 summary-feature/capacity columns rather than original within-cycle measurements.

Original study: [Severson et al., Data-driven prediction of battery cycle life before capacity degradation](https://www.nature.com/articles/s41560-019-0356-8).

Official acquisition and data-structure resources: [the dataset authors' repository](https://github.com/rdbraatz/data-driven-prediction-of-battery-cycle-life-before-capacity-degradation).

Follow the original providers' terms. Batch names and file names are retained as supplied. The original study's commonly reported124-cell count differs from this125-file collection; verify the inclusion list and physical-cell continuations before constructing battery-level folds. See [the dataset guide](../README.md) for canonical-format requirements.
