# Synthetic example artifacts

All data and weights in this directory were generated by this project's synthetic demonstration. They are not MIT/HUST records or real EV measurements and do not validate the manuscript's accuracy.

`features.csv` contains18 synthetic batteries with150 completed segments each. `best.pt` is a64-hidden-state model selected by source validation during a three-epoch demonstration. It includes source normalization and gate buffers. `model.ts` is its frozen fixed-length128 export with normalization embedded and the domain classifier removed. `manifest.json` and `export_metadata.json` describe provenance.

`replay.csv` provides chronological vectors. At150 valid vectors per cell, only the first full128-vector window produces a prediction; later160/192 triggers are checked with longer sequences in the tests.

```bash
python -m da_lss predict --checkpoint examples/synthetic/best.pt --features examples/synthetic/features.csv --output runs/example-prediction
python -m da_lss replay --checkpoint examples/synthetic/best.pt --input examples/synthetic/replay.csv --output runs/example-replay
```

Do not use these synthetic weights for real vehicle decisions or present their error metrics as a reproduction of the original experimental tables.
